# victormurcia.github.io

Personal site for **Victor Murcia, PhD** — AI engineering leader and computational scientist.
Built with Jekyll and a small, bespoke theme (no Minimal Mistakes dependency). Deployed via
GitHub Pages from the `master` branch at <https://victormurcia.github.io>.

## Structure

```
_layouts/     default, page, post          # the whole layout system
_includes/    head, seo, analytics, nav, footer
_sass/        _tokens, _base, _typography, _layout, _nav, _components
assets/css/   main.scss                     # imports the partials
assets/js/    theme-toggle.js               # light/dark toggle (progressive enhancement)
*.md / *.html  Home, About, Engineering, Research, Publications, Writing, Archive, 404
_posts/       archived earlier-work articles (URLs preserved)
img/          images (og-card, portrait, synchrotron composite, post assets)
docs/superpowers/  design spec + implementation plan for the redesign
```

## Local development

No local Ruby needed — build in Docker (uses `sassc`/libsass, matching GitHub Pages' Sass):

```bash
# production build (includes Google Analytics)
docker run --rm -v "$PWD:/srv/jekyll" -w /srv/jekyll \
  -e JEKYLL_ENV=production jekyll/jekyll:4.2.2 \
  sh -c "bundle install && bundle exec jekyll build"

# then preview the output
python -m http.server 8080 --directory _site
```

Omit `JEKYLL_ENV=production` for a development build (analytics is suppressed outside production).

## Analytics & SEO

Google Analytics (gtag) is configured in `_config.yml` under `analytics:` and injected by
`_includes/analytics.html` **in production only**. SEO metadata (title, description, canonical,
OpenGraph, Twitter, and JSON-LD `Person`) is generated by `_includes/seo.html`.
